# LambdaFlux Chapter Index

The 54 numbered chapters are original guided exercises. Chapters 01-24 cover Python through immutable materials examples; 25-42 develop the functional toolkit; 43-54 build the Dockerized REST application.

Each implementation chapter contains:

1. a scientific or mathematical motivation;
2. a small worked example that does not reveal the capstone answer;
3. numbered edits naming exact files and functions;
4. constraints and failure cases;
5. an acceptance command and observable criteria.

Use `docs/implementation-map.md` to move between source skeletons and chapters. Use `GET /v1/tutorials/{slug}` to read any chapter through Swagger.
